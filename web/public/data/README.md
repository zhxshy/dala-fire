# Data files for the web app

Generated by `scripts/06_export_web.py`. Do not edit by hand.

| File | Content |
| --- | --- |
| `celldays.parquet` | One row per day and 0.01-degree cell with a clean detection: `d` days since 2000-11-01, `ci`/`cj` cell row/column (add `grid.ci0`/`grid.cj0` from `model.json`, multiply by 0.01 for degrees), `h` harmonized fire cell-days on the VIIRS S-NPP scale, `m` sensor bitmask (1 Terra, 2 Aqua, 4 S-NPP, 8 NOAA-20, 16 NOAA-21), `r` region id |
| `days.json` | Source of the harmonized value for each day (index = days since epoch) |
| `regions.geojson` | Region boundaries, simplified; © OpenStreetMap contributors, ODbL |
| `hotspots_YYYY.parquet` | Clean detections per year, for the CSV download |
| `static_mask.json` | Centres of cells masked as static heat sources (gas flares, industry) |
| `model.json` | Factors, validation numbers, data-through date, region names |

Source data: NASA FIRMS (MODIS C6.1, VIIRS 375 m C2).
